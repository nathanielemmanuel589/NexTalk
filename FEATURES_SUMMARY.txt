┌───────────────────────────────────────────────────────────────────────────┐
│  2️⃣  DELETE FOR EVERYONE 🗑️                                               │
└───────────────────────────────────────────────────────────────────────────┘

  What you can do:
  ✅ Delete messages from BOTH chats
  ✅ Time limit: 10 minutes after sending
  ✅ Shows deletion placeholder
  ✅ Works for text, images, and files

  Options:
  📌 Delete for Me → Only removes from your chat (no time limit)
  📌 Delete for Everyone → Removes from both chats (10 min limit)

  How it looks BEFORE:
  
  ┌─────────────────────┐
  │ Oops wrong chat!    │
  │         8:30 PM  ✓✓ │
  └─────────────────────┘

  How it looks AFTER deletion:
  
  ┌─────────────────────┐
  │ 🚫 This message     │  ← Faded gray
  │    was deleted      │
  └─────────────────────┘

  How to use:
  1. Long press your message (within 10 min)
  2. Tap "Delete for Everyone"
  3. Confirm
  4. Poof! Gone from both chats! 💨

│  3️⃣  MESSAGE REACTIONS 😍                                                 │
└───────────────────────────────────────────────────────────────────────────┘

  What you can do:
  ✅ React to any message with emoji
  ✅ 6 reactions: ❤️ 👍 😂 😮 😢 🙏
  ✅ See reaction counts
  ✅ Quick toggle on/off
  ✅ Real-time updates

  How it looks:
  
  ┌─────────────────────┐
  │ Great idea!         │  ← Message text
  │                     │
  │ ❤️ 3  👍 2  😂 1    │  ← Reaction bubbles with counts
  │         8:30 PM  ✓✓ │
  └─────────────────────┘

  Your reaction:
  
  │ ❤️ 3 │ ← Blue background (you reacted)
  
  Others' reactions:
  
  │ 👍 2 │ ← Gray background (you didn't react)

  How to use:

  Method 1: Long press menu
  1. Long press any message
  2. Tap "❤️ Add Reaction"
  3. Choose emoji
  4. Done! ✨

  Method 2: Quick toggle
  1. Tap existing reaction bubble
  2. If you haven't reacted → Adds your reaction
  3. If you already reacted → Removes your reaction

╔═══════════════════════════════════════════════════════════════════════════╗
║                    🗑️  DELETE OPTIONS EXPLAINED                           ║
╚═══════════════════════════════════════════════════════════════════════════╝

  DELETE FOR ME:
  ─────────────────────────────────────────────────────────
  ✅ Available: Always (no time limit)
  ✅ Effect: Removes from YOUR chat only
  ❌ Other user: Still sees the message
  ✅ Use case: Clean up your own chat
  
  Example:
  Your chat:        Their chat:
  [empty]           "Hello there!"
  

  DELETE FOR EVERYONE:
  ─────────────────────────────────────────────────────────
  ✅ Available: Within 10 minutes only
  ✅ Effect: Removes from BOTH chats
  ✅ Shows: "🚫 This message was deleted"
  ✅ Use case: Sent wrong message, typo, regret

  Example:
  Your chat:                Their chat:
  "🚫 This message          "🚫 This message
   was deleted"              was deleted"

╔═══════════════════════════════════════════════════════════════════════════╗
║                        ⚙️  TECHNICAL DETAILS                              ║
╚═══════════════════════════════════════════════════════════════════════════╝

  DATABASE CHANGES:
  ─────────────────────────────────────────────────────────
  messages table:
    + edited_at TIMESTAMP NULL
    + is_deleted BOOLEAN DEFAULT FALSE

  New table: message_reactions
    - id (primary key)
    - message_id (foreign key)
    - user_id (foreign key)
    - reaction (emoji text)
    - created_at (timestamp)


  BACKEND ROUTES:
  ─────────────────────────────────────────────────────────
  PUT    /api/messages/edit/:messageId
  DELETE /api/messages/delete-for-everyone/:messageId
  POST   /api/messages/:messageId/reactions
  DELETE /api/messages/:messageId/reactions
  GET    /api/messages/:messageId/reactions


  SOCKET.IO EVENTS:
  ─────────────────────────────────────────────────────────
  Emit:
    - edit_message
    - delete_for_everyone
    - add_reaction
    - remove_reaction

  Listen:
    - message_edited
    - message_deleted
    - reaction_updated

  ⏰ TIME LIMITS:
  ─────────────────────────────────────────────────────────
  • Edit messages: 10 minutes
  • Delete for everyone: 10 minutes
  • Reactions: No limit
  • Delete for me: No limit

  🚫 RESTRICTIONS:
  ─────────────────────────────────────────────────────────
  • Can only edit TEXT messages (not images/files)
  • Can only edit/delete YOUR OWN messages
  • Deleted messages kept in DB (marked as deleted)
  • Each user: 1 reaction per message (can change it)

  💾 DATABASE:
  ─────────────────────────────────────────────────────────
  • Deleted messages NOT removed (is_deleted = TRUE)
  • Message text/files cleared on "delete for everyone"
  • Reactions cascade delete (if message deleted, reactions go too)

  🔄 REAL-TIME:
  ─────────────────────────────────────────────────────────
  • All changes broadcast via Socket.IO
  • Both users see updates instantly
  • Fallback to HTTP if socket disconnected
