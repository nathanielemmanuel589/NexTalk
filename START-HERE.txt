================================================================================
                        DAILY USAGE (After Setup)
================================================================================

TO START THE APP EACH DAY:

Step 1: Make sure WAMP is running (green icon in taskbar)

Step 2: Start Backend
   - Double-click: start-backend.bat
   - OR manually: Open CMD → cd backend → npm start
   - Keep this window OPEN

Step 3: Start Mobile App  
   - Double-click: start-mobile.bat
   - OR manually: Open CMD → cd mobile → npm start
   - Keep this window OPEN

Step 4: Open on Phone
   - Open Expo Go app on phone
   - Scan QR code shown in browser
   - Wait for app to load

================================================================================
                           NEED HELP?
================================================================================

❌ Backend won't start?
   → Check WAMP is running
   → Read: TROUBLESHOOTING.md

❌ Mobile app won't connect?
   → Update IP address in mobile/src/config/config.js
   → Make sure backend is running
   → Phone and computer on same WiFi

❌ Database errors?
   → Run: backend/init-database.js
   → Check phpMyAdmin

❌ Something else?
   → Read TROUBLESHOOTING.md
   → Check error messages in terminals

================================================================================

# Start mobile (from root)
npm run mobile

# Start backend (from backend folder)
cd backend && npm start

# Start mobile (from mobile folder)  
cd mobile && npm start

# Clear Expo cache
cd mobile && expo start -c
