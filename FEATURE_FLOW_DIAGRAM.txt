  🔐 PERMISSION CHECKS
═══════════════════════════════════════════════════════════════════════════

   EDIT MESSAGE:
   ─────────────
   Can edit IF:
   ✅ message.sender_id === current_user.id  (your message)
   ✅ message.message_type === 'text'        (text only)
   ✅ (now - created_at) <= 10 minutes       (time limit)
   
   Cannot edit IF:
   ❌ Someone else's message
   ❌ Image or file message
   ❌ More than 10 minutes old


   DELETE FOR EVERYONE:
   ────────────────────
   Can delete IF:
   ✅ message.sender_id === current_user.id  (your message)
   ✅ (now - created_at) <= 10 minutes       (time limit)
   
   Cannot delete IF:
   ❌ Someone else's message
   ❌ More than 10 minutes old


   DELETE FOR ME:
   ──────────────
   Can delete IF:
   ✅ message.sender_id === current_user.id  (your message)
   ✅ No time limit!
   
   Cannot delete IF:
   ❌ Someone else's message


   ADD REACTION:
   ─────────────
   Can react IF:
   ✅ Always! (any message, any time)
   ✅ No time limit
   ✅ Anyone can react to any message
   
   Note: Each user can have only 1 reaction per message
         (adding new reaction replaces old one)

  📡 SOCKET.IO EVENT FLOW
═══════════════════════════════════════════════════════════════════════════

   EMIT EVENTS (Client → Server):
   ──────────────────────────────
   
   socket.emit('edit_message', {
     messageId: 123,
     messageText: 'New text'
   });
   
   socket.emit('delete_for_everyone', {
     messageId: 124
   });
   
   socket.emit('add_reaction', {
     messageId: 125,
     reaction: '❤️'
   });
   
   socket.emit('remove_reaction', {
     messageId: 125,
     reaction: '❤️'
   });


   LISTEN EVENTS (Server → Client):
   ─────────────────────────────────
   
   socket.on('message_edited', (message) => {
     // Update message in state
     setMessages(prev => prev.map(msg => 
       msg.id === message.id ? message : msg
     ));
   });
   
   socket.on('message_deleted', ({ messageId }) => {
     // Mark message as deleted
     setMessages(prev => prev.map(msg => 
       msg.id === messageId 
         ? { ...msg, is_deleted: true, message_text: null }
         : msg
     ));
   });
   
   socket.on('reaction_updated', ({ messageId, reactions }) => {
     // Update reactions
     setMessages(prev => prev.map(msg => 
       msg.id === messageId 
         ? { ...msg, reactions }
         : msg
     ));
   });
